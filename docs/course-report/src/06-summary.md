# 总结与反思

Bilidown 是我第一次用 Rust 写的完整项目，收获颇丰：首先是我写了一个日常会用到的项目，方便了日常使用；其次，通过这个项目，我对 Rust 语言特性有了更深入的理解，尤其是所有权、生命周期、异步编程、错误处理等；另外是对 B 站接口的逆向和理解，尤其是 WBI 签名算法；最后是对下载器设计的思考，包括模块化、抽象、并发、可靠性等。


1. **WBI 签名的逆向与实现**：Web 播放/搜索接口的签名算法没有官方文档，我基本是照抄的 BBdown 的思路，把它翻译成了 Rust。
2. **异步下载的正确性**：并发分片、断点续传、临时文件原子落盘这几件事叠加在一起，边界条件很多（已下一半、分片大小不整除、主地址失败切备用等），靠针对性的测试才把它们逐个夯实。
3. **UGC 与番剧的统一**：两套接口结构不同，但下载/合并/归档逻辑相同。我把公共部分抽成 `download_source`，在不改动主流程的前提下加上了番剧支持——这让我体会到良好抽象对扩展性的价值。


感谢课程对 Rust 语言体系的讲解，让我能把所有权、并发、错误处理这些特性串联起来用到实处。开发过程中也借助了 AI 编程助手（Claude Code）辅助查阅接口资料、生成部分代码与测试、做代码审查，最终的设计、实现取舍与验证由本人完成并对结果负责。
