| 项目信息 | |
|---|---|

| 项目类型 | 命令行工具 / Bilibili 视频下载器 |

| 作者 | 胡中山 2200015477 |

`bilidown` 是一个用 Rust 编写的 Bilibili 命令行下载器。它基于 Web 端 DASH 接口获取音视频流，支持**扫码登录、关键词搜索、普通视频 / 合集 / 收藏夹 / 番剧下载、并发分片下载、断点续传**，并调用 `ffmpeg` 合并音视频，最终编译为单个可执行二进制。项目面向个人学习、资料备份和命令行自动化场景。

本报告由 [mdBook](https://rust-lang.github.io/mdBook/) 组织，共六章：

1. **项目背景与动机** —— 为什么做这个工具，为什么用 Rust。
2. **功能说明与使用方法** —— 命令一览与典型用法。
3. **项目结构与系统架构** —— 模块划分与一次下载的完整数据流。
4. **关键 Rust 设计** —— 错误处理、异步并发、所有权、枚举与模式匹配、Trait 与泛型等语言特性如何落到这个项目里。
5. **测试、验证与完成度** —— 单元测试、CI、真实接口验证与横向对比。
6. **总结与反思** —— 收获、难点与后续计划。
